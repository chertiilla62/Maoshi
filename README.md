# Maoshi — битва за двор

Онлайн party-игра на 2–8 игроков про уличных котов, которые бьются за титул **Короля двора**.
Между раундами — двор с зонами, тайный аукцион, «Кошачья свалка» (карточная драка), кошачья рулетка;
в раундах — 15 мини-игр: «Последний на заборе», «Мышиные норки», «Охота на муху», «Солнечное пятно»,
«Горячий пирожок», «Кто съел сметану?», «Ночной концерт», «Форточка», «Рыбалка лапой» и другие.
В финале — номинации и консервные банки для магазина аксессуаров.

## Технологии
- Unity **6000.3.22f1** (Unity 6.3 LTS), URP 17.3 (Forward+), свой мультяшный шейдер и контуры
- Netcode for GameObjects 2.13, Input System, UI Toolkit (интерфейс собирается кодом)
- Сеть: **Steam** (Facepunch.Steamworks 2.4.1 — лобби, приглашения друзей, свой транспорт на Steam Networking Sockets),
  без Steam — Unity Relay по коду; в локальной сети — UnityTransport с автопоиском игр
- Звук и музыка синтезированы скриптами, текстуры сгенерированы

## Как открыть проект
1. Установить Unity **6000.3.22f1** через Unity Hub (модуль Windows Build Support).
2. Купить и импортировать **[AnimX Animals: Cats](https://assetstore.unity.com/)** из Unity Asset Store в папку `Assets/AnimX Animals`.
   Это платный ассет: его файлы **не входят в репозиторий** (лицензия Asset Store запрещает их публиковать).
   Без него у котов не будет модели и анимаций.
3. Открыть папку проекта в Unity Hub. Ссылки на модели восстановятся сами (у пакета Asset Store те же GUID).
   Если коты не появились — меню **Maoshi → Setup**: Stage 8 → Stage 9 → Stage 41.
4. Сцена запуска — `Assets/_Maoshi/Scenes/Bootstrap`.

## Онлайн
- Unity Cloud: проект не привязан (в открытой копии номер облачного проекта убран). Для онлайна без Steam привяжите свой проект:
  Edit → Project Settings → Services.
- Steam: используется тестовый AppId **480** (Spacewar). Для теста добавьте собранную игру в Steam как стороннюю.
  Свой AppId — `Assets/_Maoshi/Scripts/Network/Steam/SteamService.cs`.

## Разработка
- Всё строится скриптами меню **Maoshi → Setup → Stage N** (сцены, префабы, оформление).
- **Maoshi → Test** — тестовые копии, запуск мини-игр, отладка сети.
- **Maoshi → Build → Release Build (Steam)** — релизная сборка в `Builds/Release` с отчётом о размере.
- Консоль разработчика в игре — `` ` `` (Ё) или F1, список команд — `commands`.
